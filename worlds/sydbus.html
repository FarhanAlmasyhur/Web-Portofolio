Departures come from Transport for NSW Open Data: the Trip Planner API and GTFS-realtime.

I wrote the protobuf reader by hand, so GTFS-realtime decodes with no generated code.

The screen transitions are my own kit, about ten built by hand: a split-flap board, a line flood zoom and a re-route.
